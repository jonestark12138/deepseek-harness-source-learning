# 第一讲教学简报 · 给大脑配工作室

源码快照：cd5ef8148158c3a752a658978873241fdf8e2bbc。

## 读者与问题

读者已有 Java/Spring、接口、依赖注入、文件和进程的经验，但未形成 Agent Harness 的整体图景。驱动问题：助手要排查一次测试失败，除了会分析的模型，还需要谁来组织真实动作、过程记录和继续工作？

## 叙事与负担

只用“模块化智能工作室”一个主要世界。按问题逐次出现大脑、手册与扳手、日志、材料与护栏；不在开篇塞一份架构名词表。

现在必须懂：Model 与 Harness、核心插件化、入口组装路线。
知道存在即可：Tool/Skill/Session/Filesystem/Sandbox、Profile/Bundle/Patch、Agent 与 Loop 分离。
后续深入：Cordis 生命周期、工具审批、Session 派生与持久化、循环状态机。

## 证据与完成标准

源码路线是架构说明 → bin.ts → profile-boot.ts → base 清单 → 回到 boot()。明确这是阅读路线，不是函数调用链。

完成后能闭卷讲清“会想不等于已经执行”、手册不等于工具、配置顺序不等于激活顺序；能定位六个核心配置行并说出证据不足以证明运行成功。

六份材料分工：导航、视觉课件、主讲解、折叠答案的练习、五分钟分享稿、按需词典。元数据离开读者目录，统一放在本目录。

## 视觉计划

使用 11 个独立矢量物件组合六张图。Figma 创建和精修，原生 SVG 本地保存；图中文字与箭头独立，场景配方可再生成。源码名称主要留在正文，不把插图做成目录海报。

示例“测试排查”是教学虚构，不声称真实执行。比喻、教学推断与源码事实分开记录，详见事实矩阵。
