# 第一讲重构诊断 · 本轮解决什么

## 已确认的问题

上一版已经减少 Mermaid，但混合了 editorial SVG、Excalidraw、draw.io 和时序样式。它仍更像“把名词放得更好看的技术笔记”：同一概念的物件不稳定，部分英文出现得早，五份材料重复定义，术语词典没有实际进入构建流程。

更早的“33 个 Mermaid 图块”属于历史版本，不是本轮现状，不能继续当作当前统计。

## 本轮决策

- 从“测试失败的助手有没有实际看报告”开场，制造对执行证据的需求。
- 用独立机器人、大脑、空工具箱等物件，组成一个连续的工作室世界。
- 技术对应关系放短表格和源码段落；不让 API 名称占满插图。
- 正文首次解释术语，词典负责回查，避免要求读者先背单词。
- 三种容易混淆的关系明确分开：配置应用、源码阅读、运行时序。
- 修复渲染器未纳入词典、预览导航受 base URL 影响等工程缺口。

## 不夸大的效果

已通过源码复核、脚本测试和浏览器检查；这些证明内容可追溯、构建可用、页面可读，不证明学习者一定学会。新整讲仍待用户阅读反馈。最有价值的下一次反馈是“哪张图让我想起了真实动作，哪段仍需要解释”，不是单纯增加图数。
