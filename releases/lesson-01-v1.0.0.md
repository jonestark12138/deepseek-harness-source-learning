## 怎样离线阅读

下载附件 deepseek-harness-lesson-01-v1.0.0.zip，完整解压后打开 index.html。无需安装 Node.js、Python 或启动服务器。GitHub 自动生成的 Source code 下载是工程源码，不是推荐的阅读包。

SHA256SUMS.txt 用于核对 ZIP；包内 manifest.sha256.json 记录阅读文件哈希。正文、插图、字体与素材检索无需联网；源码引用、Figma 编辑链接、下载与反馈需要联网。
