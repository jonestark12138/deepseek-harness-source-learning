# Tool selection for the workshop textbook

## Default route

Search local assets first. Figma authors/refines native vector objects; save each separately with its node link. Local scene recipes arrange them, add editable Chinese text and export deterministic, self-contained SVG. This separates reusable art from lesson-specific meaning and avoids redrawing the same robot in each figure.

Excalidraw is optional for whiteboard annotation or a specifically requested variant. Passing every figure through Figma and Excalidraw adds transformation and maintenance work without inherently improving style. Canva is optional page/slides layout. Formal Mermaid/draw.io diagrams are exceptions for relations they actually teach better, not mandatory styles in each lesson.

## Verified history, not a universal quality ranking

- Earlier Excalidraw robot/brain/toolbox sample was accepted as a direction.
- Figma native vector and handwriting samples were rendered; the independent 11-object tray was created and reviewed on 2026-09-04. After membership activation, all 11 native SVG exports succeeded.
- These Figma assets were built from editable vector geometry. Do not call them AI model-generated images.
- An earlier fal generation was blocked by exhausted balance; no output quality comparison was possible.
- Canva did not produce an accepted pictorial sample in this task.
- Subscription/API capabilities can change. Discover live tools before a new generation test; product AI features are not proof the connected tool can call them.

## When new imagery is justified

Only test another image route when the library cannot teach the needed scene, or the user requests it. Use the accepted style reference, one bounded sample, then a second consistency scene. Place Chinese labels separately. Preserve original prompts, provider/endpoint, seed if available, references and actual results. Respect authorization, price and account gates; never purchase credits implicitly.

Raster output remains raster even inside SVG. Native Figma paths are editable vectors. A scene assembled locally is not automatically a cloud Figma design; if the user needs an editable cloud scene, actually import it and retain that mapping.

Keep accepted previous work intact until replacements are validated. Machine checks, author review and user acceptance are distinct states.
